Testar SRT no FreeMix

Abra Externo → SRT/RIST. Escolha um envio SRT existente ou uma vaga livre. Preencha IP, porta e latência; a URL é montada pelo formulário. Nada transmite até você salvar e iniciar o envio.

No mesmo computador: FreeMix → vMix

  1. vMix: Adicionar Entrada → Stream / SRT → SRT (Listener), porta 18360, latência 120 ms. Comece com o decoder de hardware desmarcado.
  2. FreeMix: modo Caller, IP 127.0.0.1, porta 18360, latência 120 ms. Use H.264/x264, 1280×720 e sem alpha no primeiro teste.
  3. Abra primeiro o receptor e depois inicie o envio. Use 4:2:0 sem alpha neste vMix: o teste 4:4:4 com alpha empacotado conectou, mas o decoder encerrou a recepção. Para testar esse perfil, use OBS com decodificação por software e recomposição descrita abaixo.

Outra pessoa: ZeroTier → OBS

  1. Crie uma rede privada no ZeroTier Central. Os dois PCs entram no mesmo Network ID; autorize ambos no painel.
  2. Copie o endereço Managed IP do PC receptor. Você usa esse endereço no campo IP do receptor do FreeMix. Os IPs locais exibidos pelo formulário são deste computador, não do amigo.
  3. OBS receptor: Fonte de mídia, desmarcar Arquivo local e decodificação por hardware para o teste inicial. Entrada: srt://0.0.0.0:18360?mode=listener&latency=500000.
  4. FreeMix: Caller, IP ZeroTier do receptor, porta 18360, latência 500 ms. O firewall do receptor precisa permitir OBS/UDP nessa porta pela interface ZeroTier. Não é necessário encaminhar essa porta no roteador.

Transparência no OBS

  1. Escolha uma imagem PNG transparente, um título ou uma composição sem fundo opaco. Ative 4:4:4 e Cor + máscara no FreeMix. Para 1280×720 útil, o fluxo será 2560×720.
  2. No receptor, instale o plugin obs-shaderfilter compatível com seu OBS. O FreeMix já o inclui.
  3. Baixe o filtro de recomposição. Na fonte do OBS, adicione User-defined shader, carregar de arquivo, e selecione esse arquivo. Deixe Override entire effect desativado e expansões em zero.
  4. Depois do shader, adicione Crop/Pad relativo e corte 1280 pixels à direita no exemplo 2560×720. Isso remove a máscara e deixa a imagem com alpha em 1280×720. Para imagem útil 1920×1080, corte 1920 à direita.
  5. Coloque uma imagem por baixo para conferir as áreas transparentes e as bordas. Não corte a máscara antes do shader.

SRT 4:4:4 e recomposição de alpha passaram localmente com 320×180 lógico por dez segundos. Internet, carga Full HD e recepção contínua no OBS/vMix externo precisam ser testadas. Essa rota usa CPU/x264 e SDR; não envia um canal alpha H.264 convencional.
