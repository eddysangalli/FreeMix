Controles desta produção

OSC local bidirecional
OSC só escuta 127.0.0.1 e não inicia automaticamente. /freemix/fire recebe ID salvo, down/up e valor opcional 0–127; /freemix/subscribe recebe 1 para feedback, 0 para parar. /freemix/read recebe ID opcional. Subscribe precisa ser renovado em até 10 segundos. Talkback usa up ao soltar e /freemix/hold sem argumentos a cada 350 ms. Sem bundles nem comandos arbitrários.
NomeTecla / MIDIAçãoEstado real
Teclado funciona com a mesa ou esta janela focada. Campos de texto não acionam atalhos. Talkback precisa do mic e retorno preparados em Calls; soltar a tecla, mudar de janela ou perder o heartbeat fecha o mic privado.
Feedback mostra o estado confirmado pelo motor. MIDI Learn e retorno MIDI exigem Web MIDI, contexto seguro (HTTPS ou localhost), permissão, portas conectadas e janela focada. O CEF integrado pode não disponibilizar a API ou a permissão; nesse caso use esta tela em um navegador compatível. O retorno é mapeado explicitamente; não usa SysEx. LED/CC e fader físicos ainda precisam de homologação do dispositivo. Controladores externos podem usar /api/control com controller_fire e ID salvo; isso não constitui um plugin oficial Stream Deck/Companion.
