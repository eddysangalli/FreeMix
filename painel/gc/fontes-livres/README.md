# Fontes livres opcionais

Bebas Neue Regular foi obtida do [repositório oficial Google Fonts](https://github.com/google/fonts/tree/main/ofl/bebasneue). A licença SIL Open Font License 1.1 acompanha o arquivo, sem modificações. SHA-256 TTF: `08e4623805102d819f58601e46e345648846075e363b2ceb23313c2d1c83ec73`.

O editor oferece seu uso explícito por título; não instala fontes no Windows. Na conversão GTZIP, o opt-in de fontes copia esta fonte somente quando a família solicitada é exatamente Bebas Neue. Não há download automático no runtime. Os templates de referência e suas imagens não fazem parte desta pasta.
