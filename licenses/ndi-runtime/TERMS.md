# NDI® no FreeMix

NDI® é uma marca registrada de Vizrt NDI AB. Informações e atualizações: https://ndi.video/.

O FreeMix incorpora somente a biblioteca x64 do SDK NDI, carregada dinamicamente na pasta da própria aplicação. A biblioteca permanece licenciada pelo contrato NDI SDK License Agreement.pdf incluído aqui, que integra os termos aplicáveis ao componente NDI do FreeMix. O uso desse componente fica sujeito integralmente a esse contrato; as licenças de componentes terceiros constam de Processing.NDI.Lib.Licenses.txt. A licença do FreeMix não concede direitos adicionais sobre tecnologia NDI.

A distribuição do binário é prevista pela documentação oficial SDK, seção Software Distribution/Binary Files: https://docs.ndi.video/all/developing-with-ndi/sdk/software-distribution. SDK, ferramentas NDI, utilitários e bibliotecas de importação não são distribuídos pelo FreeMix. Não há instalação global nem mudança permanente do ambiente Windows.

Versão incluída: 6.3.2.0; SHA256 2b6602075868ba4401f82f417d72424805d69b11ca86078023d0d489ff45dd84. Proveniência completa em PROVENANCE.json.
