# Áudio remoto apareceu; sincronismo continua FAIL

Uma execução silenciosa de20s anexou a MESMA track de áudio remoto ao player de vídeo silenciado. Foram observados19 tons e19 flashes; o Worklet receptor entregou197368 amostras não zero, peak0,4500259. Antes da intervenção o receptor entregava silêncio. A diferença observada não prova causa exclusiva no navegador.

A aceitação original de sincronismo falhou:16 pares estáveis, desvio máximo82,908ms, drift9,77886ms/s e146,683ms no intervalo medido, incerteza43,379ms. Nenhuma tolerância ou relógio foi alterado para aprovar. O helper não foi integrado ao produto; vídeo contínuo das Calls permanece OFF. NativeCEF, convidados reais, N-1/talkback e WAN não foram homologados por este ensaio sintético.

HTTP/aba35 e oito recursos próprios encerrados; pós-pins passaram. Os FAILs anteriores permanecem. Os números demonstram áudio recebido neste teste, não aprovação de AV contínuo.
