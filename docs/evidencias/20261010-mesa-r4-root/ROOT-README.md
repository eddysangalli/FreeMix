Leituras concorrentes são agrupadas; conexão, coleção, UUIDs e capacidades são conferidos antes/depois de cada consulta. Uma resposta desconhecida preserva o estado confirmado anterior. A fonte foi integrada; a instalação em uso permanece intacta. Falta conferir latência, cliques e ordem das janelas na versão instalada. Isso não demonstra que todas as travas relatadas tinham esta causa. Recibos anteriores permanecem imutáveis.
