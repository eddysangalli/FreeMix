# Navegação ociosa e liberação de controles

Root integrou um arquivo: atalhos-engine.js. O original enviava controller_release no blur e um beacon no pagehide mesmo sem tecla ou MIDI acionado. A guarda nova conserva a liberação de controles pendentes/pressionados e evita esses pedidos quando a página está ociosa. Não altera comandos de corte/transmissão nem Native.

Root conferiu os dez pins do draft, executou21 modelos no IIFE real (incluindo respostas atrasadas/falhas, teclado, MIDI, botão manual, adaptador, retorno BFCache e blur repetido), verificou sintaxe e closure132. O primeiro modelo falho do agente e o App32R2 FAIL original permanecem preservados. A revisão Gemini foi acompanhada e criticada; não substitui prova real.

Ainda precisa App32R3 próprio: abrir menus sem run/execute/journal adicionais, medir Preview/Cut/persistência e fechar cooperativamente. O ledger R2 não conservou os nomes das duas ações; a correspondência com blur/pagehide permanece estática e temporal. Beacon não garante entrega; watchdog Native permanece necessário. Nenhum Native/API iniciado nesta integração, nenhum dado do operador enviado, nenhum instalador aprovado ou alterado.
